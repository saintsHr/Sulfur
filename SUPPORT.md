# Support

If you need help with Sulfur, use the appropriate channel below.

## Questions and Help

For questions about the language, compiler, documentation, or usage, open a
GitHub Discussion when available.

For reproducible bugs, use GitHub Issues instead.

## Bug Reports

Before reporting a bug:

- Make sure you are using the latest version of Sulfur.
- Check the existing Issues for similar reports.
- Include a minimal example that reproduces the problem.
- Include relevant compiler output and environment information.

## Feature Requests

Feature requests and language design proposals should be discussed through
GitHub Issues.

For significant language or compiler changes, read [`CONTRIBUTING.md`](CONTRIBUTING.md)
and [`MANIFEST.md`](MANIFEST.md) first.

## Documentation

For questions about language behavior, check the documentation in [`doc/`](doc/)
and [`MANIFEST.md`](MANIFEST.md) before opening a request.

## Security Issues

Do not report security vulnerabilities through public Issues.

See [`SECURITY.md`](SECURITY.md) for information about reporting security
issues privately.
