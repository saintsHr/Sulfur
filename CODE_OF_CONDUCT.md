# Code of Conduct

## Our Standards

Sulfur is an open project, and everyone participating in it is expected to
help maintain a respectful and constructive environment.

Contributors are expected to:

- Be respectful and professional.
- Discuss ideas and technical decisions in good faith.
- Focus criticism on the code, proposal, or implementation rather than the person.
- Accept constructive criticism.
- Respect different levels of experience and backgrounds.
- Keep discussions relevant to the project.
- Assume good faith unless there is clear reason not to.

Technical disagreement is completely normal and is part of developing Sulfur.
Disagreement should remain focused on the technical problem and its trade-offs.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, personal attacks, or targeted insults.
- Discrimination or hateful conduct.
- Threats or intimidation.
- Deliberate disruption of discussions or project work.
- Publishing private information about others without permission.
- Trolling or intentionally provoking other contributors.
- Any other behavior that would reasonably make the project hostile or unsafe
  for others.

## Issues and Discussions

Technical discussions may involve strong disagreement.

That is fine.

Arguments should be based on reasoning, implementation details, evidence,
and the project's design principles rather than personal attacks or hostility.

The `MANIFEST.md` should be used as a reference when discussing language design
and architectural decisions.

## Pull Requests and Code Review

Code review should focus on improving the code and the project.

Reviewers should explain technical concerns clearly when possible, and
contributors should treat review feedback as part of the development process.

A rejected proposal or requested change is not a personal judgment.

## Enforcement

Project maintainers are responsible for enforcing this Code of Conduct.

Depending on the situation, maintainers may:

- Ask participants to change their behavior.
- Remove inappropriate comments or content.
- Close discussions or Pull Requests that become disruptive.
- Temporarily restrict participation.
- Remove contributors from the project in serious or repeated cases.

Enforcement decisions are made at the maintainers' discretion based on the
severity and circumstances of the situation.

## Reporting

If you experience or witness behavior that violates this Code of Conduct,
report it to the project maintainers through a private communication channel
when possible.

Please include enough information to understand what happened and, when
relevant, links or other evidence.

Reports will be handled as discreetly as reasonably possible.

## Scope

This Code of Conduct applies to project spaces, including:

- GitHub Issues
- Pull Requests
- Discussions
- Code reviews
- Project-related communication

It also applies to other spaces when someone is representing the Sulfur project
or participating in an official project activity.

## Final Note

Sulfur is a technical project. Good engineering requires disagreement,
criticism, experimentation, and the ability to change one's mind.

The goal of this Code of Conduct is not to prevent disagreement, but to make
sure disagreement remains constructive and respectful.
